Политика конфиденциальности расширения Archivum

Дата вступления в силу: 24 августа 2026 г.

Эта политика относится к расширению Archivum для Chromium-браузеров. Расширение дополняет настольное приложение Archivum: добавляет элементы управления на поддерживаемых страницах YouTube и VK, определяет связанное с открытой страницей медиа и по действию пользователя передаёт выбранный материал в приложение Archivum. Загрузку и обработку выполняет настольное приложение; для некоторых VK Stories расширение открывает выбранный медиа-ресурс в браузере.

Какие данные обрабатываются и зачем

Расширение обрабатывает только данные, необходимые для этой функции:

  • URL и заголовок активной HTTP(S)-страницы после открытия пользователем popup расширения;
  • на YouTube — canonical URL текущего видео, его идентификатор из URL и заголовок страницы;
  • на VK Video и VK — URL/идентификатор открытого видео, заголовок страницы, видимое состояние видеоплеера или Story, идентификаторы Story и ссылки на медиа-ресурсы;
  • для VK Stories — URL видимого изображения или видео, когда он доступен странице;
  • для Private VK DASH — URL DASH-манифеста и, если он доступен в интерфейсе видео, идентификатор просмотрщика. URL манифеста может содержать временные параметры доступа.

На страницах VK основной скрипт расширения временно анализирует текст ответов fetch и XHR, если URL запроса содержит video, story или al_, чтобы найти ссылку на медиа-ресурс. В контексте приватного видео или личных сообщений такой ответ может содержать личную переписку либо иное приватное содержимое страницы. Расширение не предназначено для извлечения текста сообщений: оно не выделяет, не сохраняет и не передаёт текст переписки. Оно ищет только соответствующие шаблоны ссылок на медиа; при явном действии пользователя локально в Archivum передаётся только допустимый media/DASH URL и связанный идентификатор видео, а не текст сообщений.

Нажатие пользователем кнопки Archivum используется как непосредственная команда выполнить передачу или открыть выбранный ресурс. Расширение не ведёт журнал кликов, не строит профиль действий пользователя и не использует эти действия для аналитики.

Локальная обработка и хранение

Кандидаты медиа и состояние интерфейса находятся в памяти страницы или расширения и исчезают при замене страницы, перезапуске соответствующего контекста расширения либо закрытии браузера.

Расширение не использует chrome.storage, localStorage, sessionStorage, IndexedDB или собственную удалённую базу данных.

После явной передачи в Archivum Native Messaging helper может атомарно записать ограниченный запрос в локальную очередь Browser Bridge в каталоге данных текущего пользователя, чтобы запрос не потерялся при закрытом приложении. Такой запрос содержит только данные выбранного intent, перечисленные выше. Он удаляется, когда Archivum забирает его; записи считаются устаревшими через 24 часа и удаляются при следующей очистке очереди приложением или helper. На macOS каталог очереди имеет права доступа только для владельца; на Windows он располагается в каталоге данных текущего пользователя. Дальнейшее хранение созданной задачи регулируется самим настольным приложением Archivum.

Передача данных и сторонние сервисы

Расширение не отправляет пользовательские данные на серверы, контролируемые разработчиком Archivum. В нём нет аналитики, телеметрии, рекламы, трекеров и продажи данных.

По действию пользователя расширение передаёт ограниченный intent локально через Chrome Native Messaging в установленное на том же компьютере приложение Archivum. Это не передача на внешний сервер.

Для выполнения выбранного пользователем действия браузер может открыть URL исходного медиа-сервиса/CDN, а настольное приложение Archivum может обращаться к исходному сайту или CDN для получения выбранного медиа. Такие запросы обрабатываются по правилам соответствующего сайта или CDN, например YouTube или VK; расширение не передаёт эти данные отдельному серверу Archivum.

Cookies, учётные данные и журналы

Расширение не запрашивает и не использует API cookies, не читает document.cookie, не копирует и не передаёт пароли, сохранённые учётные данные, cookies или токены аутентификации. Оно не извлекает такие значения из ответов страниц и не использует их для аутентификации.

Упакованная для Chrome Web Store версия отключает development-диагностику. Она не записывает в журналы расширения полный URL медиа, заголовок страницы, текст ответа или текст личных сообщений. Ошибки и журналы браузера, сайта или настольного приложения могут регулироваться их собственными настройками.

Контроль пользователя и безопасность

Пользователь может не нажимать кнопки передачи, отключить или удалить расширение в настройках браузера. Отключение или удаление расширения прекращает его дальнейший доступ к страницам. Уже переданная локальная задача может оставаться в приложении Archivum или в очереди Browser Bridge до обработки либо следующей очистки устаревшей записи.

Расширение использует только необходимые разрешения activeTab и nativeMessaging, а контент-скрипты ограничены YouTube и VK-доменами, указанными в manifest. Native Messaging принимает ограниченные структурированные запросы и не принимает произвольные команды.

Ограниченное использование данных

Использование информации, полученной через API Chrome и доступ к страницам, ограничено предоставлением и улучшением описанной пользовательской функции передачи медиа в Archivum. Информация не используется и не передаётся для персонализированной рекламы, ретаргетинга, оценки платёжеспособности, продажи данных или иных несвязанных целей. Люди не просматривают такие данные, кроме случаев, когда это требуется законом, необходимо для безопасности либо пользователь явно запросил поддержку.

Изменения политики и контакты

При изменении способов обработки данных Archivum обновит эту страницу и дату вступления в силу до публикации соответствующей версии расширения.
